# 《未来战争》选手端说明

本仓库 `Demo/CoreGeek` 是参赛 HTTP 服务：判题器每回合 POST 当前战场 JSON，程序在 5 秒内返回本方全部角色指令。规则与字段以仓库 `docs/任务书.md`、`docs/接口文档.md` 为准。

启动：

```text
python main3.py <port>
```

进程监听 `0.0.0.0:<port>`。工作目录切到 `Demo/CoreGeek`，并把 `src` 加入 `sys.path`。

---

## 一、整体数据流

```text
判题器 POST JSON
    → main3.py 启动 HTTP
    → server.py 读请求，调用 brain.decide
    → world.py 解析完整战场
    → tasks.py 更新跨回合记忆（新闻/任务/宝藏）
    → brain.py 按白天/黑夜生成 roleCommandMap、prompt、executeCmd
        ├─ grid.py     八方向寻路
        ├─ combat.py   武器落点
        └─ protocol.py 把动作编成接口 JSON
    → debuglog.py 写本回合诊断日志
    → server.py 返回 { roleCommandMap, prompt, executeCmd }
```

每个角色每回合最多一条指令。攻击挂在**武器单位 ID** 上，`controllerId` 是站在周围一格的英雄。

## 二、目录与文件职责

### 文档（仓库 `docs/`）

| 文件 | 内容 |
|------|------|
| `docs/任务书.md` | 地图、昼夜、单位、指令、商店、机器人、任务、积分、异常口径 |
| `docs/接口文档.md` | 请求/响应字段、动作码、角色 ID 规则 |
| `docs/request.txt` | 请求样例 |
| `docs/response.txt` | 响应动作样例（同一 ID 重复出现只是目录，不是一回合多指令） |

### 入口

**`main3.py`**  
读端口、切目录、配置 stdout 日志、调用 `agent.server.serve`。不包含游戏逻辑。

**`pyproject.toml`**  
包名与 Python 版本（≥3.11），源码根为 `src/`。

### `src/agent/server.py` — HTTP 接口

`ThreadingHTTPServer` + `Handler.do_POST`：

1. 按 `Content-Length` 读 JSON。
2. `decide(payload)` 得到 `roleCommandMap`（key 为角色 ID 字符串）。
3. 从 `debuglog.last_extra()` 取出本回合 `prompt`、`executeCmd`，一并写入响应。
4. 决策异常时返回空指令表，并打 traceback，避免进程退出（异常退出不会被拉起）。

`log_message` 关闭了 http.server 默认访问日志，避免冲掉对局日志。

### `src/agent/protocol.py` — 基础数据结构与指令编码

实现接口里最常用的一层，不负责「怎么下棋」。

- 常量：白天 70 / 黑夜 60 / 一天 130 回合；武器造价 25；塔射程表。
- `Pos`：坐标；`distance` 为切比雪夫距离。
- `station_footprint`：基地 `pos` 是 2×2 左上角，展开四格（含下方一行）。
- `Unit.load` / `Robot.load` / `Turn.load`：解析 `roundNo`、`mapInfo`、`teamOur.roles`、`robot.roles`；`is_day` 由回合号对 130 取模得到。
- `Turn` 查询：基地、存活英雄/工人/武器/围墙、石矿、占格、障碍（中立格 + 己方建筑角色 + 机器人）。
- 指令函数：`move` / `collect` / `build` / `attack`，以及接口其余动作 `sell` `buy` `remove` `acceptTask` `submitAnswer` `summonTreasure` `use` `drop` 和多目标 `attack_commands`。`controllerId` 按文档发字符串。

`brain` 只通过这些函数拼响应，不手写动作 JSON。

### `src/agent/world.py` — 完整战场视图

`Turn` 只覆盖基础字段。`World.load` 先 `Turn.load`，再解析其余请求：

- 阵营、积分、`phaseTask`、`lastCmdResult`、`lastSummonTreasureResult`、`llmResp`
- `worldNews`、`vendorShopList`、`weaponShopList`、`playerTasks`
- 敌方可见单位、`lastRoundRoleActionResults`、`errors`
- 机器人类型 / 眩晕 / `targetTeam`、建筑 `attackPower`

实现方式：`World` 组合一个 `Turn`，未知属性转发到 `Turn`；`blocked` 在原障碍上再加敌方占地。另提供商店价格、己方任务点（挑战者/防守者两套 zone 名）、建造占用格、背包检索 `backpack_item` / `count_item`。`note()` 收集本回合「为什么没动手」的说明，供日志使用。

### `src/agent/grid.py` — 移动

`next_step(turn, moving, goal)`：八方向 A*（对角允许，与任务书「两障碍夹角不挡对角线」一致）。障碍来自 `turn.blocked(moving)`，不可走非 `land`。返回朝目标的**第一步**；走不到返回 `None`。

### `src/agent/combat.py` — 夜间开火选点

`attack_positions(world, tower)`：

1. 筛射程内、HP>0 的机器人，优先打 `targetTeam` 等于己方、再靠近基地的。
2. **加特林**：目标数 = 等级；任意两目标相对炮台夹角 ≤ 90°，否则少选。
3. **电磁狙击**：只打 1 点；在射程内选一条直线，按穿透规则估算伤害（能量沿路径扣减）。
4. **火箭**：目标数 = 等级；优先落在机器人堆上（落点 8 邻也算聚集）。冷却由 `brain` 看 `cooldown`，冷却中不发 `attack`。

`bomb_center`：选 3×3 内机器人尽量多的格子，供眩晕法宝/范围炸弹。

### `src/agent/tasks.py` — 跨回合记忆、任务、宝藏、LLM

进程级 `MEMORY`（HTTP 无状态，记忆靠进程常驻）：

- 按天重置 LLM 计数（非任务期每天最多 3 次；`phaseTask` 非空时不限，且不计日额度）。
- 累积官方消息、民间传闻。
- 解析 `llmResp` 中的 JSON：宝藏坐标/献祭物品/天数，或任务的 `executeCmd` / `taskAnswer`。
- 传闻启发式：坐标 `(x,y)`、中英文物品名、`第N天`。
- `summon` 结果 1 或 4 视为宝藏流程结束。
- 自进化任务：优先用上一回合 LLM 给出的命令/答案；否则按步探测沙盒（把任务写入文件 → `ls/find` → 扫文件 → 用上次输出当候选答案）。

`treasure_ready`：已有坐标和物品清单，且未到开启日则等待。

### `src/agent/brain.py` — 回合决策（核心策略）

入口 `decide`：`World.load` → `observe` → 白天 `_day` / 黑夜 `_night` → 写日志 → 返回指令表。

**白天工人**（可建造，可采集）：

1. 残血且背包有 `Medicine` 则 `use`。
2. 站在对应建筑周围一格则用升级券/围墙修复包；背包已有武器升级券则走近未满级塔。
3. 全局武器不足 3 座且金币 ≥ 25：在基地占地切比雪夫距离 1 的空地建造 **3 座火箭发射台**（先满前两座，再补第三座）。
4. 金币够买武器升级券时走到武器商店 `buy`，能升塔就先升塔。
5. 全局第 30 回合起才按基地外圈砌 `wall`（留一个缺口当出入口）；石头不够则采石。此前先按小贩现价采铜/铁/石并卖矿攒钱。
6. 否则按小贩现价去采铜/铁/石；上回合 `collect` 失败则换矿，避免死磕不可采的矿（官方消息可能导致停采）。
7. 白天最后 5 回合 **三名英雄都回塔**，不再把矿工拆去地图边缘。

**白天开拓者**：

1. 有 `phaseTask`：必须留在己方任务点周围一格（离开即任务结束），同时发 `executeCmd` 或 `submitAnswer`。沙盒命令在 `/tmp/selfEvolutionTask` 下用绝对路径读文件。
2. 否则去可领的任务点 `acceptTask`。
3. 宝藏条件满足且物品齐：走到传闻坐标周围一格 `summonTreasure`。
4. 否则协助买卖。

**黑夜**：

- 三名英雄全部就近分配给已建武器，包括矿工和仍有 `phaseTask` 的开拓者；已在周围一格则对该武器发 `attack`，否则走近。
- 开拓者若已有最终答案本回合 `submitAnswer`，否则沙盒 `executeCmd` 仍可随开火一起发出，但人必须去操塔。
- 火箭 `cooldown>0` 本回合不打。
- 背包有眩晕/炸弹且场上有聚集机器人时 `use`。

寻路目标是「目标格的相邻可站立格」，不会走进矿区、商店、任务点、建筑等阻挡格。多人移动用 `claimed` 避免抢同一格。

### `src/agent/debuglog.py` — 对局诊断日志

每回合：

- stdout（`agent.round`）
- 追加 `Demo/CoreGeek/logs/rounds.log`
- 单回合 `Demo/CoreGeek/logs/round_XXXX.log`

内容包括：昼夜与资源头信息；上回合 `lastRoundRoleActionResults=false` 的执行失败说明；`errors[]` 中文含义；召唤宝藏结果码；沙盒 `lastCmdResult`（超时 / 判题器错误 / 非 0 退出码 / 截断）；本回合发出的每条指令；未下令英雄；`prompt`/`executeCmd` 摘要；`World.notes` 里的寻路失败、冷却、射程空、任务点不可领等。

`set_extra` / `last_extra` 把 `prompt`、`executeCmd` 交给 `server.py` 填进响应。这两个字段不能塞进 `roleCommandMap`，否则判题器当角色指令解析会失败。

## 三、请求里用到的信息如何落到代码

| 请求字段 | 主要使用位置 | 用途 |
|----------|----------------|------|
| `roundNo` | `protocol.Turn` / `world.World` | 昼夜、第几天、LLM 日重置 |
| `mapInfo.zones` | `Turn.zones` | 矿、小贩、商店、双方任务点 |
| `teamOur` | `Turn` + `World` | 金币、单位、任务点状态 |
| `teamEnemy` | `World.enemy` | 寻路/建造避让；基地与围墙全图可见 |
| `robot` | `World.battle_robots` | 夜间攻击与炸弹中心 |
| `phaseTask` | `tasks` / `brain._run_task` | 是否在自进化任务中 |
| `lastRoundRoleActionResults` | `debuglog` / `brain._mine` | 失败诊断；采集失败换矿 |
| `lastSummonTreasureResult` | `tasks` / `debuglog` | 宝藏对错与是否已空 |
| `llmResp` | `tasks` | 解析宝藏 JSON 或下一句沙盒命令 |
| `worldNews` | `tasks.MEMORY` | 传闻累积；卖价以 `vendorShopList` 为准 |
| `lastCmdResult` | `tasks` / `debuglog` | 推进沙盒 SOP |
| `vendorShopList` | `World.vendor_price` | 采哪种矿、卖什么 |
| `weaponShopList` | `World.shop_item` | 购买名称与价格 |
| `errors` | `World` / `debuglog` | 超时、错答、指令错误、LLM 额度 |

## 四、和规则相关的实现要点

- 距离一律切比雪夫；「周围一格」是相邻 8 格，不站在阻挡物格子上。
- 白天禁止 `attack`：`brain` 只在 `is_day == False` 时攻击。
- 武器全局最多 3 座，造价 25，类型可混搭；新建为 1 级。
- 加特林/火箭可多目标，数量跟等级走；电磁炮单目标。
- 开拓者领任务后不能离开任务点周围一格，死亡或超时也结束任务。
- 卖矿、买物必须分别站在小贩、武器商店周围一格。
- 异常响应（超时、格式错、指令无法识别）满 5 次会被停调度；「指令合法但没打中/撞车」只算执行失败，日志按失败诊断输出，不把它写成队伍异常。

## 五、本地怎么看一场对战

1. `python main3.py <port>` 后看控制台，或打开 `Demo/CoreGeek/logs/rounds.log`。
2. 搜「上回合失败诊断」和角色 ID。
3. 对照下一回合「本回合决策」，确认是否避开了失败动作（换矿、走近商店、等冷却等）。
